
# 💳 Finance Analysis Dashboard

An interactive Power BI dashboard developed to analyze financial transactions, customer behavior, transaction performance, and fraud risk, enabling data-driven financial decision-making through interactive analytics.

---

## 📌 Project Overview

The **Finance Analysis Dashboard** provides a comprehensive analysis of financial transaction data by monitoring transaction volume, transaction amounts, customer segments, fees, taxes, transaction status, and fraud-related patterns.

The dashboard enables users to explore financial performance, analyze customer and transaction behavior, identify risk patterns, and investigate fraudulent transactions through interactive visualizations and filtering.

---

## 🎯 Objectives

- Analyze overall financial transaction performance.
- Monitor transaction volume and transaction amounts.
- Analyze customer segments and transaction behavior.
- Evaluate transaction fees and taxes.
- Identify fraudulent and high-risk transactions.
- Analyze transaction patterns across different categories and regions.
- Support data-driven financial and risk management decisions.

## 📑 Dashboard Pages

### 1. Overview Analysis

Provides a high-level overview of financial transactions and customer activity.

The page allows users to analyze transaction amounts, transaction volume, customer segments, transaction status, merchant categories, and other important financial metrics.

---

### 2. Transactions

Provides a detailed view of individual financial transactions.

Users can explore transaction-level information and apply filters to investigate specific transaction types, customers, categories, locations, and transaction statuses.

---

### 3. Risk Analysis

Focuses on fraud detection and transaction risk.

The page analyzes fraudulent transactions, risk bands, transaction channels, customer segments, merchant categories, and other factors associated with financial risk.

The Key Influencers visual helps identify factors that may contribute to fraudulent transactions.
